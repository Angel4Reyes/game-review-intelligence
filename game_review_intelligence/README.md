# GameSense

GameSense is a Python-based game review intelligence and recommendation platform.

The project analyzes game reviews and metadata to identify sentiment, common topics,
player opinions, and similarities between games.

## Goals

- Practice Python project organization
- Apply NLP techniques to game reviews
- Build a content-based recommendation system
- Process larger datasets using DuckDB and Parquet
- Create an interactive visualization dashboard
- Practice testing, Git, GitHub, and reproducible project setup

## Planned Features

- Review data cleaning
- Sentiment classification
- Game keyword and topic analysis
- Similar-game recommendations
- Interactive dashboard
- Scalable data-processing pipeline

## Project Status

Currently in the initial setup and data exploration phase.

## Planned Technology

- Python
- Pandas
- Scikit-learn
- DuckDB
- PyArrow
- Streamlit
- Plotly
- Pytest
